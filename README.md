# Video Editing Project

## Folder Structure

| Folder | Kya daalna hai |
|---|---|
| `input/` | Aapka apna short video (jo edit karna hai) |
| `reference/` | Reference video (jis style me edit chahiye) |
| `export/` | Final edited video yahan aayegi |

## Workflow

1. Apna video `input/` me upload karein.
2. Reference video `reference/` me upload karein.
3. Claude se edit karne ko bolein — final video `export/` me milegi.

> Note: GitHub web upload ki limit 25 MB per file hai, aur git push ki 100 MB.
